What is Nova AI?

Nova is a free, local voice AI assistant for Windows. People searching for an offline-friendly desktop assistant, a Python voice bot, or an alternative to cloud-only smart speakers use Nova for speech-to-text, spoken replies, long-term memory, notes, preferences, camera vision, and browser automation — all from one app on their own PC.

Unlike many online chatbots, core memory and the control panel stay on your machine (%APPDATA%\Nova on Windows). You do not need a paid API key to start listening and talking. English, Hindi, and Malayalam are supported for input and replies.

One-click setup

The auto installer handles pip packages, optional vision stack, and the YOLO model. You only need Python 3.10+ on the machine.

  1. Install Python

    Get Python 3.10 or newer from python.org. On Windows, check Add Python to PATH.

  2. Put the files together

    Download at least nova.py, setup_nova.py, and (on Windows) setup_and_run.bat into the same folder. Optional: requirements.txt, yolov8n.pt, kochi_intelligence_map.html.

  3. Run the auto installer

    Windows — double-click setup_and_run.bat, or open a terminal in that folder:

    python setup_nova.py

    The script will:

    • create a local .venv (optional, recommended)
• upgrade pip
• install core + optional packages
• download yolov8n.pt if missing
• launch Nova
  4. Allow mic (and camera if used)

    Windows may ask for microphone permission the first time. Say something after the calibration beep, or use the on-screen controls.

Frequently asked questions

Is Nova AI free to download?

Yes. Nova is free to download and run on your own PC. No cloud account is required for core features.

Does Nova need the internet after install?

Speech recognition and edge-tts voices use online services. Core GUI and local memory work offline. Vision model is local once yolov8n.pt is present. Hindi/Malayalam translation needs a network call.

How do I install Nova voice assistant on Windows?

Install Python 3.10 or newer, download nova.py and setup_nova.py into one folder, then double-click setup_and_run.bat or run python setup_nova.py. The auto installer creates a virtual environment, installs packages, downloads the vision model, and launches Nova.

Why is the first install slow?

Optional packages include PyTorch, MediaPipe, and Ultralytics. Those are large. The app still starts without them; features that need them load on demand and will tell you if something is missing.

Where is my data stored? Is it private?

On Windows: %APPDATA%\Nova\ (memory JSON, permanent archive, log). The app does not upload your conversation history to a Nova server.

How do I build a full installer (.exe)?

Use the included packaging files: put nova.py, nova.spec, installer.iss, nova_icon.ico, yolov8n.pt, and kochi_intelligence_map.html together, install PyInstaller and Inno Setup, then run build.bat. Output lands in installer_output\NovaSetup.exe.

Microphone errors or “already inside a context manager”

Only one listener should own the mic. Restart Nova fully if a previous session crashed mid-listen. Close other apps that hold the microphone exclusive.
